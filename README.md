# FoliGo website

React + Vite + Tailwind CSS site for FoliGo, deployed to GitHub Pages.

- Run locally: `npm install` then `npm run dev`
- Edit content: `src/App.jsx` (text lists are at the top of the file)
- Brand colors: `src/index.css` (`bg-pine`, `text-champagne`, etc.)
